# 个人数字花园 · 博客系统

一个前后端分离的现代化个人博客系统，依据《个人数字花园-博客系统需求规格说明书》（V1.0）实现。系统整合了**个人展示、作品沉淀、社交互动、个性化工具**四大能力，可作为个人长期使用的专属博客，也可作为前后端实战项目。

## 功能总览

**内容与展示**

- 首页：欢迎语、个人头像/横幅、最新杂谈（5-8 条）、精选项目
- 项目作品集：卡片展示封面/标题/简介/彩色技术栈标签，外链新窗口打开，后台自由增删改
- 照片墙：瀑布流布局、图片懒加载、Lightbox 放大预览、按年份/相册筛选
- 杂谈博客：Markdown 图文混排、按时间倒序、每篇独立评论区（支持博主回复）
- 留言板：访客匿名/自定义昵称留言，博主后台回复与删除
- 关于页：图文并茂个人介绍 + 底部社交链接一键跳转
- 个人资料卡：侧边栏常驻展示头像、姓名、简介、职业、所在地、邮箱
- 友链：卡片式站点展示 + 友链申请说明

**个性化与工具**

- 日夜主题切换：CSS 变量全局配色 + LocalStorage 持久化 + 平滑过渡
- 全局个性化设置：主题、字体大小、过渡动画开关，全部本地持久化
- 在线音乐播放器：悬浮右下角、播放/暂停/上一曲/下一曲/列表循环、LRC 歌词逐行滚动高亮

**后台管理（仅博主）**

- 文章 / 项目 / 照片 / 友链 / 音乐的增删改
- 留言回复与删除、评论删除
- 站点设置与社交链接维护

## 技术栈

- 前端：Vue 3 + Vite + Pinia + Vue Router + Marked
- 后端：Node.js + Express 5
- 数据库：SQLite（Node 内置 `node:sqlite`，无需额外安装）
- 鉴权：HMAC 签名令牌 + scrypt 密码哈希
- 音乐：原生 `<audio>` + 前端 LRC 解析

## 快速开始

### 环境要求

- Node.js ≥ 20（推荐 22+，内置 `node:sqlite`）
- 包管理器：npm

### 1. 安装依赖

```bash
# 后端
cd server
npm install

# 前端
cd ../client
npm install
```

### 2. 构建前端

```bash
cd client
npm run build
```

### 3. 启动服务

```bash
cd ../server
npm start
```

启动后访问 <http://localhost:3000> 即可。后端首次启动会自动创建数据库并写入示例数据。

## 开发模式

前端开发服务器（带热更新，自动代理 `/api` 与 `/uploads` 到后端）：

```bash
cd client
npm run dev       # http://localhost:5173
```

后端开发模式（文件变更自动重启）：

```bash
cd server
npm run dev       # http://localhost:3000
```

## 后台登录

- 访问 <http://localhost:3000/admin/login>
- 默认账号：`admin`，默认密码：`admin123`

可通过环境变量修改初始密码（首次启动前设置）：

```bash
# Windows (PowerShell)
$env:ADMIN_PASSWORD="你的密码"

# macOS / Linux
ADMIN_PASSWORD=你的密码 npm start
```

其它可配置环境变量：`PORT`（服务端口，默认 3000）、`DB_PATH`（数据库文件路径）、`ADMIN_SECRET`（令牌签名密钥，生产环境务必修改）。

## 内容管理指南

### 上传图片（头像 / 项目封面 / 照片 / 友链 Logo / 歌曲封面）

后台各表单里的「上传图片」按钮会打开**应用内弹窗**（切到其他标签页也不会丢失），支持点击选择或直接拖拽文件：

1. 进入后台 → 找到对应内容（文章、项目、照片、友链、音乐、设置）；
2. 点「上传图片」→ 弹出填写框：可以直接**粘贴图片地址**点「使用此地址」，也可以点「从本地上传」选图或拖入图片后上传；
3. 弹窗是**模态框**，打开时会挡住后台页面，需要点右上角 ✕（或按 Esc）关闭后，才能继续操作其他页签；
4. 表单会自动填入图片地址，保存即可。

图片大小上限 10MB。

### 导入真实的歌曲

**方式一：后台直接上传（推荐）**

1. 进入后台 →「音乐」→「新增曲目」（或编辑已有曲目）；
2. 点「上传歌曲文件」选择 mp3 / wav / ogg / m4a / flac 等音频（上限 45MB）；
3. 点「上传 LRC 歌词」选择 `.lrc` 标准歌词文件（播放时逐行滚动高亮）；
4. 点「上传封面图」选一张歌曲封面；
5. 填写曲名、艺术家、排序，保存。

**方式二：手动放文件（适合大批量）**

1. 把 `歌曲.mp3` 和 `歌曲.lrc` 放进 `client/public/music/`；
2. 在后台「音乐」里新增曲目，音频地址填 `/music/歌曲.mp3`，歌词地址填 `/music/歌曲.lrc`；
3. 重新执行 `npm run build` 让文件进入构建产物。

> LRC 是标准的歌词文本格式，形如 `[00:12.34]歌词内容`，可用任意文本编辑器编写，或从音乐软件导出。

## 重新生成示例资源

占位图、合成背景音乐与 LRC 歌词均由脚本生成，可随时重新生成：

```bash
node scripts/generate-assets.mjs
```

## 说明

- 示例图片为渐变占位 SVG，示例音乐为程序合成的轻音乐（WAV），歌词为原创文案，均可自由替换为真实素材。
- 数据库文件位于 `server/data/blog.db`，删除该文件后重启即可恢复初始示例数据。
- 评论、留言写接口内置了基础频率限制（见 `server/src/middleware.js`）。
