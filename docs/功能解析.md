# 个人数字花园博客系统（exhibition hall）功能解析

## 一、总体架构

前后端分离的单体应用：前端 `client/`（Vue 3 + Vite + Pinia + Vue Router），后端 `server/`（Node.js + Express 5 + SQLite）。后端生产模式同时托管前端构建产物，`npm start` 后访问 `:3000` 即可使用整站。

## 二、后端（server/）

### 入口与中间件（src/index.js）

- 请求日志只记录 `/api`（`DISABLE_REQUEST_LOG=1` 可关闭）
- CORS 支持 `CORS_ORIGIN` 限制来源；JSON 体上限 64MB（支持图片/音频 base64 上传）
- 上传接口按扩展名白名单（图片/音频/LRC）并分级限大小
- 托管前端 + HTML 不缓存；错误兜底中间件；生产默认密钥告警

### 数据层（src/db.js）

- 启动建表 + 自动补列迁移（`ensureColumn`），不覆盖已有数据
- 表：settings / users / posts / projects / photos / comments / messages / links / music / playlists / collections
- 音乐歌单：music 含 playlist_id / duration / source，外键级联置空
- 全文索引：posts_fts、projects_fts（FTS5 + trigram），写后自动重建

### 鉴权与工具

- auth.js：scrypt 密码哈希 + HMAC 签名令牌；helpers.js：统一 ok/fail/validate；middleware.js：内存限流

### 路由模块（src/routes/）

- settings/auth/posts/projects/photos/comments/messages/links/music/collections/search
- posts：列表区分公开与后台（`?all=1` 含草稿）、定时发布可见性、详情支持管理员取全文
- comments：文章评论与合集评论二选一归属
- music：曲目/歌单 CRUD、m3u/pls/xspf/zip 导入、酷狗/网易云/QQ 链接导入、音频下载代理
- collections：合集 CRUD，列表带数量与封面兜底

### 歌单解析器（src/playlistParser.js）

- 文本歌单解析、zip 解压与音频落盘（防目录穿越）、平台页面抓取解析

### 测试（test/smoke.mjs）

- 63 项接口自动化：公开接口/鉴权/校验/CRUD/草稿定时/FTS/合集/歌单导入

## 三、前端（client/）

### 入口与布局

- router.js（history 模式 + `/admin` 守卫）；App.vue（导航 + 内容 + 悬浮播放器 + 日间卡 + 设置抽屉 + Toast）
- TopNav：站名 + 8 导航 + 搜索 + 设置/后台入口（中英双语）

### 状态（stores/）

- app.js：主题（日/夜）、主题色预设、语言、字体、动画、登录态、站点资料
- music.js：曲目/歌单、播放与歌词状态、音频单例（跨页不中断）、搜索与歌单过滤

### 页面（views/）

- HomeView：资料卡 + 欢迎卡 + 音乐卡 + 「展览精品」
- ProjectsView / ProjectDetailView：项目网格 + 详情
- PhotosView（时光印染）：拍立得合集卡片 → 合集详情；下方只显示未入合集照片
- CollectionDetailView：大拍立得头部 + 照片 + 评论
- BlogView / PostView：文章列表 + Markdown 详情 + 评论
- ArchiveView：全息时间轴（Three.js 3D）与列表视图切换
- MusicView：音乐列表（歌单/搜索过滤、点歌播放）
- GuestbookView / LinksView / AboutView / SearchView
- AdminView / AdminLoginView：全站后台管理

### 组件与基础设施

- components：TopNav、DayToggle、MusicPlayer（可拖拽）、SettingsDrawer、PostCard、ProjectCard、MusicCard、CommentSection、Lightbox、AppIcon、AppToast、UploadModal（裁剪/压缩/EXIF）、MarkdownRenderer
- src：api.js（鉴权/错误处理）、toast.js、i18n.js、tags.js、styles/main.css（深浅主题 + 主题色）、vendor/three（本地化 Three.js）

## 四、特色功能链路

- 展览精品：文章/项目勾精选 → 首页展示，无精选回退最新
- 全文搜索：FTS5 命中文章/项目，短词或不可用回退 LIKE
- 照片合集：建合集 → 照片归集 → 拍立得展示 → 详情 + 评论
- 3D 全息归档：Shader（菲涅尔/扫描线/噪波）+ 5s 明暗 + Raycaster 交互，可切列表
- 上传管线：比例裁剪 → 压缩 WebP → EXIF 填年份 → 白名单落盘
- 音乐/歌单：手动上传 + 文件/zip/平台链接导入 + LRC 歌词
- 草稿与定时发布；多主题与中英国际化

## 五、后续可优化方向

阅读量统计、RSS/sitemap、评论防垃圾与邮件通知、列表分页、对象存储/CDN、Docker 部署与数据库迁移/备份。
